# Persian Translation of WooCommerce Min/Max Order Plugin

## معرفی پروژه

این پروژه نسخه فارسی‌سازی شده افزونه **WooCommerce Min/Max Order** است که
با هدف استفاده راحت‌تر کاربران فارسی‌زبان در فروشگاه‌های ووکامرسی آماده شده
است.

نسخه اصلی این افزونه از مخزن رسمی وردپرس دریافت شده و تمامی بخش‌های متنی،
پیام‌های خطا، اعلان‌ها و قسمت‌های مدیریتی آن برای استفاده در سایت‌های
فارسی‌زبان ترجمه و بهینه‌سازی شده است.

------------------------------------------------------------------------

## هدف توسعه

این پروژه برای فروشگاه اینترنتی [Banycker](https://banycker.com/) توسعه
و فارسی‌سازی شد.

نیاز اصلی کارفرما، ایجاد امکان تعیین **حداقل و حداکثر مقدار سفارش قابل
ثبت توسط مشتریان** در فروشگاه بود تا مدیریت سفارش‌ها مطابق قوانین فروشگاه
انجام شود.

پس از بررسی نسخه اصلی افزونه، تمامی بخش‌های مورد نیاز برای استفاده در
محیط فارسی‌سازی و آماده بهره‌برداری شد.

------------------------------------------------------------------------

## تغییرات انجام شده

### فارسی‌سازی بخش کاربری (Frontend)

-   ترجمه تمامی پیام‌های نمایش داده شده به مشتری
-   فارسی‌سازی خطاهای مربوط به محدودیت سفارش
-   ترجمه پیام‌های نمایش داده شده در صفحه سبد خرید
-   ترجمه پیام‌های مربوط به فرآیند خرید
-   بهبود تجربه کاربری برای فروشگاه‌های فارسی‌زبان

------------------------------------------------------------------------

### فارسی‌سازی بخش مدیریت وردپرس (Admin Panel)

-   ترجمه متدها و متن‌های موجود در بخش مدیریت
-   فارسی‌سازی تنظیمات مرتبط با محصولات ووکامرس
-   ترجمه گزینه‌های مربوط به تعیین حداقل و حداکثر سفارش
-   آماده‌سازی افزونه برای استفاده راحت مدیران سایت

------------------------------------------------------------------------

## ویژگی‌های افزونه

-   تعیین حداقل مقدار سفارش برای محصولات ووکامرس
-   تعیین حداکثر مقدار سفارش برای محصولات ووکامرس
-   نمایش پیام مناسب هنگام رعایت نشدن قوانین سفارش
-   سازگار با فرآیند خرید ووکامرس
-   فارسی‌سازی کامل رابط کاربری و پیام‌های افزونه

## نحوه استفاده

1.  افزونه را دانلود کنید.
2.  پوشه افزونه را در مسیر زیر قرار دهید:

``` text
wp-content/plugins/
```

3.  از بخش مدیریت وردپرس وارد قسمت:

``` text
افزونه‌ها > افزونه‌های نصب شده
```

شوید.

4.  افزونه را فعال کنید.

5.  تنظیمات مربوط به حداقل و حداکثر سفارش را مطابق نیاز فروشگاه انجام
    دهید.
