# WordPress Custom Login URL & Admin Protection

## معرفی پروژه

این Repository شامل مجموعه‌ای از کدهای PHP برای **تغییر آدرس پیش‌فرض ورود
وردپرس، تغییر مسیر خروج کاربران و افزایش امنیت بخش مدیریت وردپرس** است.

در حالت پیش‌فرض، صفحات ورود و مدیریت وردپرس از مسیرهای مشخصی مانند:

``` text
/wp-login.php
/wp-admin
```

در دسترس هستند. این موضوع می‌تواند باعث افزایش درخواست‌های مخرب، حملات
Brute Force و شناسایی راحت‌تر ساختار سایت توسط افراد غیرمجاز شود.

با استفاده از این کدها می‌توان بدون نیاز به نصب افزونه، مسیر ورود وردپرس
را شخصی‌سازی کرده و دسترسی کاربران مهمان به بخش مدیریت را محدود کرد.

------------------------------------------------------------------------

## هدف توسعه

هدف از ایجاد این کد، ارائه یک راهکار ساده، سبک و قابل اعتماد برای افزایش
امنیت سایت‌های وردپرسی است.

در برخی پروژه‌ها که امنیت اهمیت بالایی دارد، استفاده از افزونه‌های جانبی
برای تغییر مسیر ورود ممکن است گزینه مناسبی نباشد. در چنین شرایطی،
پیاده‌سازی مستقیم این قابلیت در فایل‌های قالب وردپرس می‌تواند کنترل بیشتری
روی عملکرد سیستم ایجاد کند.

این روش بدون اضافه کردن وابستگی جدید به وردپرس، قابلیت تغییر آدرس ورود و
محدودسازی مسیرهای حساس را فراهم می‌کند.

------------------------------------------------------------------------

## قابلیت‌ها

-   تغییر آدرس پیش‌فرض صفحه ورود وردپرس
-   جلوگیری از دسترسی مستقیم به `wp-login.php`
-   تغییر مسیر بعد از خروج کاربر
-   محدودسازی دسترسی کاربران مهمان به `wp-admin`
-   جلوگیری از نمایش صفحه مدیریت به کاربران غیرمجاز
-   عدم نیاز به نصب افزونه
-   پیاده‌سازی مستقیم با PHP و توابع استاندارد وردپرس

## نحوه استفاده

این کدها باید داخل فایل زیر قرار بگیرند:

``` text
functions.php
```

در مسیر قالب فعال وردپرس:

``` text
wp-content/themes/your-theme/functions.php
```

------------------------------------------------------------------------

## تغییر آدرس ورود

در بخش‌های زیر:

``` php
home_url('/your-url.php')
```

مقدار:

``` text
your-url.php
```

را با آدرس دلخواه خود تغییر دهید.

مثال:

``` php
home_url('/secure-login.php')
```

بعد از اعمال تغییرات، مسیر ورود سایت به شکل زیر خواهد بود:

``` text
example.com/secure-login.php
```

## عملکرد کد

### تغییر مسیر صفحه ورود

این بخش درخواست‌های ورود پیش‌فرض وردپرس را بررسی کرده و کاربر را به مسیر
سفارشی هدایت می‌کند.

مسیرهای محافظت شده:

``` text
/wp-login.php
/wp-admin
```

------------------------------------------------------------------------

### تغییر مسیر خروج

بعد از خروج کاربر، به جای مسیر پیش‌فرض وردپرس، کاربر به آدرس تعیین شده
منتقل می‌شود.

------------------------------------------------------------------------

### محدود کردن wp-admin برای کاربران مهمان

اگر کاربری وارد سایت نشده باشد و تلاش کند به بخش مدیریت وردپرس دسترسی
پیدا کند:

-   درخواست بررسی می‌شود.
-   دسترسی مستقیم محدود می‌شود.
-   صفحه 404 نمایش داده خواهد شد.

این محدودیت برای جلوگیری از نمایش مسیرهای مدیریتی سایت به کاربران
غیرمجاز اعمال می‌شود.
